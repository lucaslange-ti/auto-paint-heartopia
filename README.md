# Auto Paint Heartopia

Pinta uma imagem automaticamente no canvas do jogo **Heartopia**: você escolhe a
imagem, o programa converte para as cores do jogo e clica sozinho, célula a
célula. Grátis.

## Requisitos

- Windows 10 ou 11
- O jogo Heartopia rodando no PC (janela visível na tela)

O runtime WebView2, se faltar, é instalado automaticamente durante a instalação.

## Como baixar e instalar

1. Baixe o `AutoPaintHeartopia-win-Setup.exe` na
   [página de Releases](https://github.com/lucaslange-ti/auto-paint-heartopia/releases).
2. Execute o instalador. Como o programa ainda não é assinado, o Windows pode
   mostrar um aviso azul do **SmartScreen** — clique em **Mais informações →
   Executar assim mesmo**.
3. Abra o **Auto Paint Heartopia** pelo atalho criado na área de trabalho.

O programa **se atualiza sozinho**: ao abrir, ele verifica se há versão nova e
pergunta se quer atualizar.

## Como usar

1. Deixe o jogo aberto com o canvas de pintura visível.
2. No programa, siga o assistente:
   - **Imagem** — escolha o arquivo e confira o preview já convertido.
   - **Calibração** — marque a área do canvas e as cores da paleta do jogo
     (guiado, uma vez só; fica salvo).
   - **Pintura** — clique em iniciar e não mexa no mouse/teclado até terminar.
3. Durante a pintura:
   - **Ctrl+Alt+Espaço** — pausar / retomar
   - **Ctrl+Alt+X** — abortar

O idioma (português / inglês) e outras opções ficam em **Configurações**.

## Aviso

Automatizar ações pode violar os termos de uso do jogo. Use por sua conta e
risco.
